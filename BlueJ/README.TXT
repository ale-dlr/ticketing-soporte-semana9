PROJECT TITLE: Sistema de Tickets de Soporte Técnico Corporativo
PURPOSE OF PROJECT: Desarrollar un sistema de gestión de soporte técnico aplicando Programación Orientada a Objetos (POO) en Java/BlueJ. Incluye clases abstractas, herencia y polimorfismo para la gestión de tickets (Incidentes y Requerimientos con SLA), usuarios (Técnicos y Solicitantes), control de flujos de estado y funciones recursivas de escalamiento.
VERSION or DATE: Versión 2.0 - Septiembre 2026
HOW TO START THIS PROJECT: 1. Abrir BlueJ y seleccionar "New Project..." creando una carpeta llamada "SistemaTickets".
2. Crear las clases correspondientes (Main, Ticket, TicketIncidente, TicketRequerimiento, Usuario, Tecnico, Solicitante, GestorTickets, FlujoTicket).
3. Copiar y pegar el código fuente provisto en cada clase y hacer clic en el botón "Compilar".
4. Hacer clic derecho sobre la clase "Main", seleccionar el método `main(String[] args)` y presionar "Ok" para iniciar la consola interactiva.
AUTHORS: Alejandra de la Rosa
USER INSTRUCTIONS: El sistema muestra un menú por consola con 10 opciones interactivas.
- Ingrese opciones del 1 al 10 según lo que desee realizar (ver usuarios por polimorfismo, crear tickets de incidente o requerimiento, registrar errores, resolver, cerrar casos o escalar recursivamente).
- Para el correcto funcionamiento, siga las instrucciones de entrada solicitadas en la consola de ejecución de BlueJ.
